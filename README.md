Norman Borlaug Tribute Page

An editorial-style tribute page about Norman Borlaug, the agricultural scientist whose work helped improve food production and reduce hunger worldwide.

Instead of using a typical card layout, this project uses a magazine-inspired visual direction with a large image hero, elegant typography, a quotation section, and a timeline.

Features

Responsive editorial hero layout

Portrait image with an accessible caption

Clear heading hierarchy and semantic HTML

Timeline of Norman Borlaug's life and work

Quote section with attribution

External link with a visible keyboard-focus state

Responsive design for mobile screens

Built With

HTML5

CSS3

What I Practiced

CSS Grid layouts

Image cropping with object-fit: cover

Absolute positioning for image captions

Responsive typography using clamp()

Pseudo-elements for timeline markers

Semantic elements such as main, figure, figcaption, blockquote, and article

Accessible links and descriptive alternative text
